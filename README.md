# 🚰 Health Reminder - 健康提醒助手

一个功能强大的桌面应用，帮助你养成良好的生活习惯，定时提醒饮水和休息。

## ✨ 功能特性

- **🚰 饮水提醒**
  - 自定义饮水间隔时间（默认30分钟）
  - 每日饮水目标和统计
  - 记录每次饮水时间

- **🧘 休息提醒**
  - 多种休息类型（眼睛休息、站起活动、肩颈拉伸等）
  - 自定义休息间隔和持续时间
  - 休息建议和指导

- **📊 数据统计**
  - 每日饮水统计
  - 周/月饮水趋势
  - 完成率追踪
  - 历史记录查看

- **🔔 智能提醒**
  - 系统通知弹窗
  - 声音提醒（可选）
  - 托盘图标快速操作
  - 提醒历史记录

- **⚙️ 自定义设置**
  - 灵活的提醒间隔配置
  - 活动时间段设置（工作时间）
  - 提醒音量和类型选择
  - 外观主题切换

## 🛠️ 技术栈

- **Python 3.9+**
- **PyQt6** - 跨平台 GUI 框架
- **SQLite** - 本地数据存储
- **APScheduler** - 定时任务调度

## 🎯 使用指南

### 基本操作
1. **启动应用**：运行 `python main.py`
2. **设置提醒间隔**：点击 "设置" 按钮自定义时间
3. **启用提醒**：切换开关启用饮水和休息提醒
4. **查看统计**：在 "统计" 标签页查看今日完成情况

### 快速记录
- 点击 "立即饮水" 快速记录一次饮水
- 点击 "现在休息" 记录休息并重置计时器

### 自定义设置
在设置中可以配置：
- 饮水提醒间隔（15-120分钟）
- 休息提醒间隔（20-120分钟）
- 工作时间段（自动暂停非工作时间提醒）
- 通知音量和类型
- 应用主题

## 🎵 提醒类型

### 饮水提醒建议
- 常规：温和的提醒铃声
- 重要：更突出的提醒音
- 静音：仅显示弹窗

### 休息建议
1. **眼睛休息**（20-20-20法则）
   - 每20分钟，看20秒远处，20英尺外
   
2. **站起活动**
   - 站起来，走走，放松双腿
   
3. **肩颈拉伸**
   - 简单的颈部和肩膀拉伸
   
4. **深呼吸**
   - 做5次深呼吸，放松身心

## 💾 数据存储

所有数据存储在本地 SQLite 数据库中：
- 提醒配置
- 每日记录
- 历史统计
- 用户设置

数据隐私：所有数据完全本地存储，不上传任何信息。

## 🐛 常见问题

**Q：应用无法启动？**
A：确保已安装所有依赖，运行 `pip install -r requirements.txt`

**Q：通知不显示？**
A：检查系统通知权限设置，Windows/Mac/Linux 可能需要授权

**Q：如何卸载应用？**
A：删除应用文件夹即可，数据会保存在 `~/.health_reminder/` 目录
